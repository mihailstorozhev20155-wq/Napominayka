# Напоминайка

Милое Android-приложение напоминаний.

## Что умеет
- Создание напоминаний с датой и временем
- Полноэкранный экран срабатывания с маскотом
- Текст: «Настюша! Милая ты просила напомнить:»
- Повторы: ежедневно / по будням / еженедельно / ежемесячно
- Отложение (snooze)
- История событий
- Расширенные настройки:
  - точные будильники
  - время отложения по умолчанию
  - вибрация / звук
  - держать экран включённым
  - очистка истории и всех напоминаний

## Сборка
Сборка выполняется GitHub Actions.  
Debug APK появляется в Actions → workflow `Android Debug APK` → Artifacts.

Локально:
```bash
./gradlew assembleDebug
```
